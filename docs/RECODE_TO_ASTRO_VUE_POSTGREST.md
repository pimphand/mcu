# Recode MCU App: Laravel -> Astro + Vue.js + PostgREST

## 1. Tujuan

Merecode aplikasi MCU (Medical Check Up) saat ini yang berbasis **Laravel 11 + Blade + jQuery (Vuexy Theme) + Vite** menjadi **Astro + Vue 3 + PostgREST**.

Yang diminta:
- Frontend pakai **Astro + Vue.js** (gunakan Vue component sebagai island/interaktif)
- Semua data dipindah ke **PostgreSQL** dan di-expose via **PostgREST** (ganti Eloquent/Controller REST internal Laravel)
- Struktur rapi, bisa dipahami & dikembangkan lanjut
